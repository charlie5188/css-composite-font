# Composite Font Studio

复合字体工坊 · 複合字型工坊 · 合成フォント工房

Build a composite font the way InDesign does: a separate font, size and baseline for CJK ideographs, kana, punctuation, Western text and digits, tuned for every weight, proofed live, and exported as CSS for the web or as font files for apps that have no composite fonts.

**Try it: <https://charlie5188.github.io/css-composite-font/>** The interface is in English, 简体中文, 繁體中文 and 日本語.

[日本語](#日本語) · [简体中文](#简体中文) · [繁體中文](#繁體中文)

## Why

A plain `font-family` fallback picks fonts, but it can't make the Western font a little larger to match the CJK character face, decide whether quotes and dashes come from the CJK or the Western font, or keep the balance right as text gets bolder. This tool does all of that with standard CSS, so it works in every current browser.

## Highlights

- **Per character class.** CJK ideographs, kana, Western text, digits, full-width punctuation, symbols, punctuation shared by CJK and Western text, and Zhuyin each get their own font, size and baseline, plus your own exception characters. Type size and baseline values directly, or use the up/down arrows to adjust them by 0.5. Pulsing gray font dots mean loading; red dots mean loading failed. Hover or focus a dot for its status or failure reason; dots disappear when ready. Status reflects the font actually used in the preview, checking the full variable weight range in Continuous mode.
- **Save your setup.** The first preset card always shows the current setup, using the same suggested name as the save dialog when unnamed and keeping existing names. Save it as a new preset with an editable name filled in from its main fonts (numbered to avoid duplicates), or explicitly save changes to your own preset. Replacing a saved preset requires a second click to confirm; presets stay in this browser and exclude font files. Filters apply to the other cards.
- **Weight-aware.** Settings made at 400 carry over to every weight; a weights table shows and tunes size and weight per weight. For variable fonts, type any weight or use the arrows on the right or keyboard ↑↓ to adjust it by 10 (Shift + ↑↓ for 100). Static Google Fonts step by 100, skipping unavailable weights. Arrows appear on hover or focus and stay visible on touch screens; the numbers stay aligned as the arrows appear or disappear. In Continuous mode, setting the preview or web page to `font-weight: 450` displays variable fonts at 450. Values outside a font’s supported range use the nearest endpoint; static fonts use the nearest weight. Individual variable font weight adjustments are temporarily ignored and restored when you switch to Stepped. Click empty space in a selected row to preview its weight without changing the export selection. Click the B icon or preview weight field to open a slider. You can also type a number or drag B; the number updates as you adjust it. Stepped mode previews only selected export weights, shown as slider stops. Continuous mode adjusts smoothly within the export range, with clickable marks for 400 (Regular) and 700 (Bold) when they fall within that range. Endpoints and shortcut labels share one row below the slider; endpoint labels are omitted when too close to a shortcut. Removing the current preview weight selects the nearest remaining weight. Typed values outside the range or between selected weights snap to an available value when committed. Changing fonts or followed classes in stepped mode unchecks export weights outside the actual mappings’ known ranges. Valid mappings and unknown ranges are kept; undo or select weights again to restore them. The reset button beside a class heading restores its base size, baseline and adjustable weight and clears its per-weight overrides. It keeps the base font choice and other classes, and can be undone. Sliders use the same neutral colors as buttons, with horizontal track endpoints aligned to thumb centers and ticks. In Continuous mode, drag the two handles beside the weight rows to choose an export range in steps of 100. Rows outside the range stay visible but inactive, and their saved adjustments are kept. The range still includes intermediate weights; exact endpoints can be entered in Export. Keyboard arrows move a handle by 100, or 10 with Shift. A drag is saved on release and can be undone in one step; Escape cancels it. When the table has only size columns, it uses one header row, such as "Han size" and "Western size". Static fonts with adjustable weights keep the two header rows for class names, weight and size.
- **Auto-adjust.** Match independently chosen Western, digit, kana, punctuation, symbol and Zhuyin fonts by class. Western text uses the Han font; independent digits use the fitted Western text; CJK classes use corresponding characters in the Han font. Following classes inherit, and supported single-class exception groups use their original class. Missing references and mixed exception groups keep their settings and are reported. Size and baseline are fitted in both modes; stepped mode can also choose closer available weights. Results can be fine-tuned or undone in one step. Notices slide in from the bottom, pause, then fade out; reduced motion disables animation. Weight matching also works in older browsers. If a selected additional variation axis cannot be measured, that class keeps its settings and is reported.
- **Appearance and preview colors.** Settings offers Light, Dark and System modes. The proof toolbar’s View menu lets you customize the proof background and text colors. Changes apply immediately to the proof and metric chart, can be reset to theme defaults, and stay in this browser across preset changes. They are excluded from presets, share links and all exports. Settings and View group related controls and share consistent label alignment and spacing.
- **Share a configuration.** Copy a snapshot link from Share, beside Export. Recipients can preview, edit and save the configuration without an account. Links exclude font files, custom proof text, history and other saved presets. Google Fonts reload; local fonts and uploaded files must be available on the receiving computer. Imports can be undone.
- **Three outputs.** Paste-ready CSS (usually a few KB, the CJK font linked from Google Fonts); TTF / OTF / WOFF2 files baked in the browser for Figma, Keynote, Word and the like; and, experimentally, Swift / Kotlin / Flutter code that applies the same rules in native apps.
- **Any font.** Browse real specimens from Google Fonts, search names and aliases, and filter known styles or bold support. The initial order follows the class and proof language; unknown metadata stays eligible and checks never reorder results. Choose installed fonts by family and style, or reuse imported files within the page session (reload requires the files again). Preview class samples, matching proof text or custom text without saving preview edits. Applied settings are separate, with optional automatic matching for non-Han selections and a single undo step. Relevant coverage notices stay visible; details expand on demand. Search, loading, permission and failure have distinct feedback, including retry for slow loads and unknown coverage when checks fail.
- **Regionally correct.** Checks glyph forms and punctuation position for Simplified, Taiwan, Hong Kong and Japanese text, can scope the CSS to one language, and exports native CSS properties from the Text layout tab, such as `text-autospace` and `line-break`. Preset names describe font pairings; labels identify the script and region.


## Development

No build step: `python3 tools/serve.py` serves the page at http://127.0.0.1:8765/. `npm run setup` once, then `npm run verify` runs every check CI runs. Conventions and code layout are in [AGENTS.md](AGENTS.md).

## 简体中文

**复合字体工坊**像 InDesign 的复合字体一样，为汉字、假名、标点、西文、数字分别指定字体、大小和基线，按字重微调，实时校样，然后导出：网页用的 CSS，或者给不支持复合字体的软件用的字体文件。

- **按字符类别设定。** 汉字、假名、西文、数字、标点、符号、中西共用标点、注音各自指定字体、大小和基线，还能添加例外字符。大小和基线可直接输入，也可用上下箭头每次微调 0.5。 字体名前的灰色闪烁点表示正在加载，红点表示失败；悬停或聚焦可查看状态与失败原因，加载完成后隐藏。状态对应当前预览实际使用的字体，连续模式检查整条可变字重轴。
- **保存当前配置。** 预设首张卡片固定显示当前编辑内容；尚未命名时显示与保存框一致的建议名称，已有名称保留。可存为新预设，名称按主要字体组合自动填写，重名时加序号，也可自行修改；已有预设可明确保存修改。覆盖需再次点击确认；只保存在当前浏览器，不包含字体文件。筛选只作用于后面的卡片。
- **照顾到每个字重。** 在 400 设定的内容会推算到所有字重，「各字重」一览表里可以按字重调整大小和粗细。可变字体的粗细可直接输入任意数值，右侧箭头或键盘 ↑↓ 每次增减 10，Shift + ↑↓ 每次增减 100；静态 Google Fonts 字体按 100 档调整，缺档时跳到下一个可用字重。箭头在悬停或聚焦时出现，触屏上常显；显示与隐藏不会改变数字的对齐位置。连续模式下，预览或网页设为 `font-weight: 450`，可变字体就显示 450；超出字体支持范围时使用最近的端点，静态字体使用最接近的一档。可变字体的单独粗细调整暂不生效，切回分档即可恢复。点击已勾选行的空白处即可预览该字重，不会改变导出勾选。点击校样工具栏的 B 图标或字重框可展开滑杆，也可直接输入数字或拖动 B 图标；数字会实时同步。分档模式只预览已勾选的字重，滑杆显示对应节点；连续模式在导出范围内无级调整，范围内的 400（Regular）和 700（Bold）刻度可点击跳转。范围端点与常用刻度统一显示在滑杆下方，过近的端点文字会省略。取消当前预览的字重时，自动切到最近的已勾选字重；输入范围外或未勾选的值，确认时也会收进可用范围。分档模式换字体或改变跟随关系时，会按各行实际映射自动取消越界的导出字重；有效映射和未知范围保留，可撤销或重新勾选。 类别标题旁的重置按钮恢复该类别的基础大小、基线和可调字重，并清除逐档调整，保留基础字体选择与其他类别，可撤销。滑杆统一使用与按钮一致的黑白配色，横向轨道两端与滑块中心及刻度对齐。连续模式在表格左侧拖动两个滑块，按 100 一档选择导出范围。范围外的行保留并置灰，已有调整不会丢失；范围内仍包含中间字重。精确端点可在「导出」中输入。键盘方向键每次移动 100，配合 Shift 每次移动 10。拖动在松手时保存，可一次撤销，Esc 取消本次拖动。表格只有大小列时，使用「汉字大小」「半角西文大小」等单行表头；有静态字体可调粗细时，保留类别与粗细、大小两级表头。
- **自动调整。** 按类别匹配独立指定的西文、数字、假名、标点、符号与注音字体。西文参照汉字字体；独立数字参照本次调整后的西文；CJK 类别参照汉字字体中的对应字符。跟随项继承，符合条件的单一类别例外组参照原类别。缺少可靠参照、混合类别的例外组保持原设置并提示。两种模式都调整大小与基础基线，分档模式还可选择更接近的可用字重。结果可微调，整次操作可一次撤销。操作提示从屏幕底部滑入，停留后淡出；系统开启「减少动态效果」时直接显示。 旧版浏览器仍可自动匹配字重；若无法测量所选的其他可变轴，该类别保留原设置并提示。
- **外观与校样颜色。** 设置中可选浅色、深色或跟随系统；校样工具栏的「显示」菜单可自定义背景色与文字颜色，即时应用到校样与度量图，可恢复主题默认颜色。这些偏好只存在当前浏览器，换预设时保留，不进入预设、分享链接或任何导出。 设置与显示弹层按功能分组，标签、控件和说明使用统一的对齐与间距。
- **分享配置。** 点击「导出」旁的「分享」复制当前配置的链接，接收方无需账号即可预览、编辑或存为预设。链接不包含字体文件、自定义校样正文、历史记录或其他已存预设。Google Fonts 会重新加载，本机字体与上传文件需接收方补齐；导入可撤销。
- **三种导出。** 可以直接粘贴的 CSS（汉字字体从 Google Fonts 引用时通常只有几 KB）；在浏览器里生成的 TTF / OTF / WOFF2 字体文件，给 Figma、Keynote、Word 等软件用；以及实验性的 Swift / Kotlin / Flutter 代码，在原生 App 里按同样的规则排字。
- **什么字体都能用。** 浏览 Google Fonts 的真实字样，搜索名称、别名，按已知风格或粗体能力筛选。初始顺序按类别与校样语言安排，未知资料保留，检查后不重排。本机字体按家族与样式选择；导入的文件可在本页复用，重新载入后需重新提供。可试用类别样张、校样同类文字或自定义内容，预览编辑不保存。应用设置单独分组，非汉字类别可自动匹配，并随字体选择一次撤销。相关缺字提示直接显示，其他详情按需展开。搜索、加载、授权与失败分别反馈，加载过久可重试，检查失败不会冒充全部支持。
- **照顾地区差异。** 检查简体、台湾、香港、日文的字形和标点位置，可以把 CSS 限定在某个语言，也会导出 `text-autospace`、`line-break` 等 CJK 排版属性。 预设名称描述字体搭配，简繁与地区由卡片标签区分。

## 繁體中文

**複合字型工坊**像 InDesign 的複合字型一樣，為漢字、假名、標點、西文、數字分別指定字型、大小與基線，按字重微調，即時校樣，再匯出成網頁用的 CSS，或給不支援複合字型的軟體使用的字型檔案。

- **依字元類別設定。** 漢字、假名、西文、數字、標點、符號、中西共用標點、注音各自指定字型、大小與基線，也能加入例外字元。大小與基線可直接輸入，也可使用上下箭頭每次微調 0.5。 字型名前的灰色閃爍點表示正在載入，紅點表示失敗；將滑鼠移到狀態點上或以鍵盤聚焦，可查看狀態與失敗原因，載入完成後隱藏。狀態對應目前校樣實際使用的字型，連續模式檢查整條可變字重軸。
- **儲存目前設定。** 第一張預設集卡片固定顯示目前編輯內容；尚未命名時顯示與儲存畫面相同的建議名稱，已有名稱則保留。可另存預設集，名稱依主要字型組合自動填入，重名時加上編號，也可自行修改；已有預設集可明確儲存變更。覆寫須再次點選確認；只儲存在目前瀏覽器，不包含字型檔案。篩選只套用至後面的卡片。
- **照顧每個字重。** 在 400 設定的內容會推算到所有字重，「各字重」表格裡可以按字重調整大小與粗細。可變字型的粗細可直接輸入任意數值，右側箭頭或鍵盤 ↑↓ 每次增減 10，Shift + ↑↓ 每次增減 100；靜態 Google Fonts 字型按 100 檔調整，缺檔時跳到下一個可用字重。箭頭在滑鼠停留或聚焦時出現，觸控螢幕上持續顯示；顯示與隱藏不會改變數字的對齊位置。連續模式下，校樣或網頁設為 `font-weight: 450`，可變字型就顯示 450；超出字型支援範圍時使用最接近的端點，靜態字型使用最接近的一段。可變字型的個別粗細調整暫不生效，切回分段即可恢復。點選已勾選列的空白處即可預覽該字重，不會改變匯出勾選。點選校樣工具列的 B 圖示或字重欄位可展開滑桿，也可直接輸入數字或拖曳 B 圖示；數字會即時同步。分段模式只預覽已勾選的字重，滑桿顯示對應節點；連續模式在匯出範圍內無段調整，範圍內的 400（Regular）與 700（Bold）刻度可點選跳轉。範圍端點與常用刻度統一顯示在滑桿下方，過近的端點文字會省略。取消目前預覽的字重時，自動切換至最接近的已勾選字重；輸入範圍外或未勾選的值，確認時也會調整至可用範圍。分檔模式更換字型或改變跟隨關係時，會依各列實際對應自動取消超出範圍的匯出字重；有效對應與未知範圍保留，可復原或重新勾選。 類別標題旁的重設按鈕會恢復該類別的基礎大小、基線與可調字重，並清除各字重的個別調整，保留基礎字型選擇與其他類別，並可復原。滑桿統一使用與按鈕一致的黑白配色，水平軌道兩端與滑塊中心及刻度對齊。連續模式在表格左側拖曳兩個滑塊，以 100 為單位選擇匯出範圍。範圍外的列會保留並顯示為灰色，原有調整不會遺失；範圍內仍包含中間字重。精確端點可在「匯出」中輸入。鍵盤方向鍵每次移動 100，搭配 Shift 每次移動 10。拖曳在放開時儲存，可一次復原，Esc 取消這次拖曳。表格只有大小欄時，使用「漢字大小」「半形西文大小」等單列表頭；有靜態字型可調整粗細時，保留類別與粗細、大小兩層表頭。
- **自動調整。** 依類別調整獨立指定的西文、數字、假名、標點、符號與注音字型。西文參照漢字字型；獨立數字參照本次調整後的西文；CJK 類別參照漢字字型中的對應字元。跟隨項目繼承，符合條件的單一類別例外群組參照原類別。缺少可靠參照、混合類別的例外群組保留原設定並提示。兩種模式都調整大小與基礎基線，分段模式也可選擇較接近的可用字重。結果可微調，整次操作可一次復原。操作提示從螢幕底部滑入，停留後淡出；系統開啟「減少動態效果」時直接顯示。 舊版瀏覽器仍可自動比對字重；若無法測量所選的其他可變軸，該類別保留原設定並提示。
- **外觀與校樣顏色。** 設定中可選擇淺色、深色或跟隨系統；校樣工具列的「顯示」選單可自訂背景色與文字顏色，即時套用到校樣與度量圖，可恢復主題預設顏色。這些偏好只儲存在目前瀏覽器，切換預設集時保留，不包含在預設集、分享連結或任何匯出內容中。 設定與顯示選單依功能分組，標籤、控制項與說明使用一致的對齊與間距。
- **分享設定。** 點選「匯出」旁的「分享」複製目前設定的連結，接收方無須帳號即可預覽、編輯或存為預設。連結不包含字型檔案、自訂校樣內文、歷程紀錄或其他已存預設。Google Fonts 會重新載入，本機字型與上傳檔案需由接收方補齊；導入可復原。
- **三種匯出。** 可直接貼上的 CSS（漢字字型從 Google Fonts 引用時通常只有幾 KB）；在瀏覽器裡產生的 TTF / OTF / WOFF2 字型檔案，供 Figma、Keynote、Word 等軟體使用；以及實驗性的 Swift / Kotlin / Flutter 程式碼，在原生 App 裡依相同規則排字。
- **各種字型都能用。** 瀏覽 Google Fonts 的實際字樣，搜尋名稱與別名，依已知風格或粗體支援篩選。初始順序依類別與校樣語言安排，未知資料保留，檢查後不重新排序。本機字型依字族與樣式選擇；匯入的檔案可在本頁重複使用，重新載入後須重新提供。可試用類別樣張、校樣同類文字或自訂內容，預覽編輯不儲存。套用設定獨立分組，非漢字類別可自動調整，並隨字型選擇一併復原。相關缺字提示直接顯示，其他資訊依需要展開。搜尋、載入、授權與失敗分別回饋，載入過久可重試，檢查失敗不視為全部支援。
- **照顧地區差異。** 檢查簡體、臺灣、香港、日文的字形與標點位置，可以將 CSS 限定為特定語言，也會匯出 `text-autospace`、`line-break` 等 CJK 排版屬性。 預設名稱描述字型搭配，簡繁與地區由卡片標籤區分。
