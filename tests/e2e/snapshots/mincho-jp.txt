 * 汉字基础字体用 @import 直接引用 Google Fonts，排在 font-family 的第二位；
 * 下面只定义需要覆盖它的类别：用 unicode-range 接管字符，用 size-adjust 调整大小。
 * 同名 @font-face 中，浏览器从最后一条往前匹配。 */
/* 斜体：每组规则另有一份 font-style: italic。有斜体的类别用斜体字体（或倾斜轴）；
 * 没有斜体的类别（汉字、假名等）用正体文件、也声明成 italic，浏览器就不会把它们模拟倾斜。 */
/* font-variation-settings 用于细调可变字体的粗细和其他轴：Chrome 140+、Firefox 62+ 支持；Safari 不认这一行，粗细按 font-weight 那一档、其他轴按字体的默认值显示。 */
/* ascent-override / descent-override / line-gap-override：西文等规则使用汉字字体的行高度量（已除以 size-adjust），
 * 行高和基线位置都和汉字字体一致。Chrome 87+、Firefox 89+ 支持；Safari 会忽略，按各字体自己的度量显示。 */
