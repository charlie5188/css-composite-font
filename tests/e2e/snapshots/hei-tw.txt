 * 行高和基线位置都和汉字字体一致。Chrome 87+、Firefox 89+ 支持；Safari 会忽略，按各字体自己的度量显示。 */

/* 用法：给元素加 class="composite"。
 * 不要在这些元素上设置 font-size-adjust：它会让上面各条规则里的 size-adjust 失效。 */
.composite {
  font-family: "My Composite", "Noto Sans TC", sans-serif;
  text-autospace: normal;          /* 中西间距 · Chrome 140 · Firefox 145 · Safari 18.4 */
  text-spacing-trim: trim-start;   /* 标点挤压 · Chrome 123 · Firefox — · Safari — */
  line-break: strict;              /* 禁则 · Chrome 58 · Firefox 69 · Safari 11 */
  hanging-punctuation: allow-end;  /* 标点悬挂 · Chrome — · Firefox — · Safari 10 */
  font-synthesis-style: none;      /* 没有斜体的字保持正体，不让浏览器模拟倾斜 · Chrome 97 · Firefox 111 · Safari 16.4 */
}
